# Serve — Outfit Planner

Closet browser + outfit builder. Soft maximalist fashion UI for a resume-ready React portfolio piece.

## Run

```bash
npm install
npm run dev
```

Opens on Vite (default `http://localhost:5173`).

## What ships

- Wardrobe piece browser with seed clothing items
- Soft maximalist UI (Syne + Nunito, blush/mint atmosphere)
- Navigation, empty + loading states
- Outfit builder + saved looks **stubs** with TODOs

## Rename checklist

1. Update `src/config/site.ts` (`name`, `resumeTitle`, `tagline`, `description`)
2. Update `index.html` `<title>` + meta description
3. Swap `public/favicon.svg`
4. Optionally rename `package.json` `"name"`
5. Update GitHub repo / Vercel project display name

Visible branding should read from `siteConfig` only.
